# Famlo Font web CSS

All five WOFF2 files are publicly available from the Famlo GitHub repository and can be served through jsDelivr:

```css
@font-face { font-family: "Famlo"; src: url("https://cdn.jsdelivr.net/gh/Famloindia/famlo-website@main/public/fonts/Famlo-Light.woff2") format("woff2"); font-weight: 300; font-style: normal; font-display: swap; }
@font-face { font-family: "Famlo"; src: url("https://cdn.jsdelivr.net/gh/Famloindia/famlo-website@main/public/fonts/Famlo-Regular.woff2") format("woff2"); font-weight: 400; font-style: normal; font-display: swap; }
@font-face { font-family: "Famlo"; src: url("https://cdn.jsdelivr.net/gh/Famloindia/famlo-website@main/public/fonts/Famlo-Medium.woff2") format("woff2"); font-weight: 500; font-style: normal; font-display: swap; }
@font-face { font-family: "Famlo"; src: url("https://cdn.jsdelivr.net/gh/Famloindia/famlo-website@main/public/fonts/Famlo-SemiBold.woff2") format("woff2"); font-weight: 600; font-style: normal; font-display: swap; }
@font-face { font-family: "Famlo"; src: url("https://cdn.jsdelivr.net/gh/Famloindia/famlo-website@main/public/fonts/Famlo-Bold.woff2") format("woff2"); font-weight: 700; font-style: normal; font-display: swap; }
```

Then use:

```css
body { font-family: "Famlo", sans-serif; font-weight: 400; }
h1 { font-weight: 700; }
```
